#
#   ## <lesson number> | <lesson title from the book>
#   english | slovak
#   english | slovak | hint
#
# Rules
#   - The lesson number (1–13) is the lesson's permanent ID. The order of the
#     blocks in this file does not matter; the menu shows the highest number first.
#   - Lines starting with a single # are comments and are ignored.
#   - Words may contain letters and spaces only – the child has to type them.
#     No brackets, apostrophes, hyphens or digits. Capital letters are kept
#     exactly as written (Earth) and shown that way; typing them is case-insensitive.
#   - The optional 3rd column is a hint. It is only SHOWN next to the English word
#     (e.g. "globe (model)"), never typed. Use it when two rows have the same
#     English word, like "globe" below.
#   - "Final Revision" is built automatically from all lessons. Do not add it here.
#   - Save the file as UTF-8 (so č, š, ž, á, ó … survive), then refresh the page.
#   - If a line has a problem, the Science screen shows an orange warning with
#     the line number (all of them: press F12 → Console).
# ─────────────────────────────────────────────────────────────────────────────
